好久没有写日记了

2026-05-22 1 分钟阅读 # 日记 # 妈妈 # 思考

日记（修改版）

1. 好久没有写日记了。有时候断了，就不想写了。但想想，每天如果能写一下日记，其实也是一个好习惯。也算是一天平庸生活中，难得的一段内心平静时刻，此刻可以想想现在的生活，想想以后，想想过去。不管好与坏，都应该好好珍惜当下的时光。

2. 今天，妈妈去医院把引流管拔了，不知道之后会怎么样。医生的建议是希望我们继续化疗，可是我怕妈妈受不了。虽然前两次化疗的效果很好，肿瘤缩小了，但我也不知道是否应该继续化疗，真的很矛盾。目前的方案是每两个月复查一次，如果有变化，就继续化疗。

3. 自己每天除了工作、担心母亲之外，也不知道做什么。想多看看电影，看看日本的生活剧，散散心，也是对自己生活的一种思考。什么才是自己想要的生活？以自己当下的状态，我应该放宽心态去面对，想办法不让时间白白流逝。

4. 昨天，想起了那个很久没联系的相亲女孩，就是上次见面时对方很热情的那个。其实，那次见面结束之后，她就依旧很冷淡。这不是对方的问题，她应该能感觉到我不是很喜欢她，有些东西是没办法作假的。再加上她在北京工作，双方都不可能辞去工作，现实点说，我们是不可能的。做人就要果断一点，拖拖拉拉不好。
