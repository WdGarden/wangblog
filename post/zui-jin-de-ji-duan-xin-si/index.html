最近的几段心思

2026-10-21 1 分钟阅读 # 生活 # 随笔 # 感悟 # 思考 # 社会 # 相亲 # 心情 # 妈妈 # 反思

一

最近很喜欢看旅游博主的视频。有个叫小钟的博主，去了非洲、东南亚很多国家，拍当地的人文和社会环境。东南亚不少国家还很穷，贫富差距很大，跟我们八十年代差不多。中国一万块，在当地能买很多东西。有些地方的贫民窟，过得真不是人过的日子。

联想到这些，再看我们现在的生活——国家当然有很多不足，但比起他们，我们真的算不错了。以前我常抱怨社会上的不公，现在想想，我们已经做得够好了。希望中国能慢慢变好。

二

最近，日常任务做完以后，最让我烦心的就是找对象这件事。真的希望自己能尽快找到合适的，然后结婚。

三

还有个心里的念头。最近，我不想再因为妈妈的病伤心难过了。这对我的消耗太大，每天都抑郁。我也想开了：人的命我改变不了，都是注定的，我改变不了什么。

希望活着的时候好好活着，走的时候好好告别。自己的心要狠一点，勇敢面对会发生的事。过好当下的日子，也很重要。希望自己慢慢恢复状态。加油，给以后的路好好打底。不管怎样，既然活着，日子就得好好过。希望自己勇敢。
