英语学习 - too vs very

2026-04-03 1 分钟阅读 # 日记 # 英语 # 学习

English listening practice - BBC Learning English. Today I’m going to tell you how to use ’too’ and ‘very’. They are both intensifiers – but they don’t mean the same thing.

🔊 听力原文

英文原文 中文翻译与解析
Hi, I’m Phil from BBC Learning English. 大家好，我是BBC英语学习的菲尔。
Today I’m going to tell you how to use ’too’ and ‘very’. 今天我要告诉你们如何使用"too"和"very"。
They are both intensifiers – but they don’t mean the same thing. 它们都是程度加强词——但意思并不相同。
We use ‘very’ to make an adjective, or an adverb stronger. 我们用"very"来加强形容词或副词的强度。
If we use ’too’ (with two Os), then it means it’s a problem. 如果我们使用"too"（两个o），那就意味着这是一个问题。

Just remember that if we use ’too’, it’s a problem.
